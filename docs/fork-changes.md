# 本项目的定制体验

以用户视角记录本项目相对上游 getpaseo/paseo 的现有差异。修改定制功能时，直接更新对应条目。

核对日期：2026-10-30。对照定制开始前的上游提交 `1aef1ec66`，仅列本项目的改动，不包含同步上游带来的功能或已撤销的尝试。

## Android：按项目找对话

| 上游体验                      | 本项目体验                                                                                   |
| ----------------------------- | -------------------------------------------------------------------------------------------- |
| 侧栏以 workspace 为主         | 按项目列出未归档对话，跨 workspace 汇总，项目内按最近活动排序                                |
| 进入 workspace 后再选对话     | 点击侧栏对话，直接打开对应聊天；每条对话显示自己的状态                                       |
| 从项目进入新建 workspace 流程 | 项目旁直接新建对话；添加或克隆项目后也直接进入新对话输入页                                   |
| 新建时需要考虑 workspace      | 优先复用项目根目录的普通 workspace，没有时才创建；不会为每条新对话新建 workspace 或 worktree |

多个对话可以共用一个工作目录，各自保留聊天上下文、标题和运行状态。它们修改的是同一份文件，因此文件改动会互相可见。旧对话仍保留原来的 workspace 归属，不会自动合并。

新建对话需要主机支持同一项目下多个 workspace；旧主机会提示更新。

## Android：聊天页围绕当前对话

- 顶部显示当前对话标题，隐藏 workspace 标签栏；从侧栏切换对话。
- 顶部更多菜单收纳文件侧边栏开关和上下文详情，输入框不再显示上下文按钮；侧栏每条对话的菜单和顶部菜单都提供重命名、归档。归档正在运行的对话前会确认。
- 菜单只保留操作项，不重复显示对话标题；附件加号菜单也去掉标题，沿用共用菜单间距。
- 缩小导航栏与状态栏之间的空白，标题和按钮保持同一行。
- 隐藏语音入口，保留文字和附件输入；输入框保持原有宽度。

## 文件 diff 工具栏

右侧文件 diff 面板的“展开所有文件／折叠所有文件”移出更多菜单，直接放在刷新与更多按钮之间。其他使用同一工具栏的面板同步生效。

## 默认设置

以下是新安装或尚未保存对应设置时的默认值，已有设置继续保留。

| 设置              | 上游默认              | 本项目默认                                                 | 范围         |
| ----------------- | --------------------- | ---------------------------------------------------------- | ------------ |
| AI 工作时发送消息 | 引导当前任务（steer） | 排队，等待当前任务结束                                     | 所有客户端   |
| 用量显示          | 已用                  | 剩余                                                       | 所有客户端   |
| 侧栏入口          | 上游默认入口          | 隐藏新建 workspace、历史、定时任务，显示搜索；底部显示用量 | 所有客户端   |
| 界面字号          | 原生端 15             | 原生端 16                                                  | Android、iOS |

## 共用界面的调整

这些调整没有限定 Android，也会影响使用相应组件的其他平台：

- 紧凑布局中的共用菜单统一增加上下留白和行间距，包含对话、附件及其他使用同一菜单组件的入口。
- 待发送消息在限定高度内滚动，避免队列把输入区挤出屏幕。
- 紧凑布局顶部只留一行标题，去掉副标题、主机信息和原来的标签切换入口。
- 通用对话列表取消长按归档；Android 从侧栏或聊天页的对话菜单归档。

## Android：与原版同时安装

定制版和上游原版可以在同一台手机共存，应用数据和主机配对分别保存。切换到定制版需要重新配对，原版数据不会自动带过来。

安装标识、构建和调试方式见 [Android 文档](android.md#app-variants)。
