# 本项目的定制体验

以用户视角记录本项目相对上游 getpaseo/paseo 的现有差异。修改定制功能时，直接更新对应条目。

核对日期：2026-11-06。对照上游提交 `6c1b48d29`，仅列本项目的改动，不包含同步上游带来的功能或已撤销的尝试。

## Android：按项目找对话

| 上游体验                      | 本项目体验                                                                                   |
| ----------------------------- | -------------------------------------------------------------------------------------------- |
| 侧栏以 workspace 为主         | 按项目列出未归档对话，跨 workspace 汇总，项目内按最近活动排序                                |
| 进入 workspace 后再选对话     | 点击侧栏对话，直接打开对应聊天；每条对话显示自己的状态                                       |
| 从项目进入新建 workspace 流程 | 项目旁直接新建对话；添加或克隆项目后也直接进入新对话输入页                                   |
| 新建时需要考虑 workspace      | 优先复用项目根目录的普通 workspace，没有时才创建；不会为每条新对话新建 workspace 或 worktree |

多个对话可以共用一个工作目录，各自保留聊天上下文、标题和运行状态。它们修改的是同一份文件，因此文件改动会互相可见。旧对话仍保留原来的 workspace 归属，不会自动合并。

新建对话需要主机支持同一项目下多个 workspace；旧主机会提示更新。

项目分组标题不显示项目图标，保留项目名称和展开／收起箭头。

## Android：聊天页围绕当前对话

- 顶部显示当前对话标题，隐藏 workspace 标签栏；从侧栏切换对话。
- 顶部更多菜单收纳文件侧边栏开关和上下文详情，输入框不再显示上下文按钮；侧栏每条对话的菜单和顶部菜单都提供重命名、归档。归档正在运行的对话前会确认。
- 菜单只保留操作项，不重复显示对话标题；附件加号菜单也去掉标题，沿用共用菜单间距。
- 缩小导航栏与状态栏之间的空白，标题和按钮保持同一行。
- 隐藏语音入口，保留文字和附件输入；输入框保持原有宽度。

## 文件 diff 工具栏

右侧文件 diff 面板的“展开所有文件／折叠所有文件”移出更多菜单，直接放在刷新与更多按钮之间。其他使用同一工具栏的面板同步生效。

## 一键导入 Codex 对话（所有客户端）

侧边栏底部问号旁提供“一键导入 Codex 对话”；窄侧栏放不下时收进底部更多菜单。选择主机后，导入其当前 Codex 配置下未归档的主对话，已有项目复用，没有的项目自动添加。导入关联原 Codex 会话，可以继续聊天；不会创建 Codex 对话副本。

重复点击复用正在执行的任务；已接入 Paseo 的对话（含已归档记录）自动跳过。任务在主机逐条执行，关闭面板或手机断线后继续；主机重启后需重新点击，已完成的不会重复导入。面板显示进度、结果和失败原因，重试只补剩余对话。已删除目录的对话会报告失败。导入后的空闲运行进程会释放，打开对话时恢复。

只读取所选主机的 Codex 数据，不同步其他电脑或仅在云端的记录。切换 Codex 与 Paseo 继续同一对话前，让另一端停止操作；两端界面不保证实时更新。

## Codex 归档同步（所有客户端）

每次在 Paseo 打开对话（含切回已打开的标签页），先检查 Codex 的归档状态；已归档则同步到 Paseo 并刷新活动列表，查看历史不会自动取消归档，继续聊天需明确取消归档。打开时的检查不受 15 秒间隔限制，检查失败则显示加载错误，重试后重新检查。

刷新对话列表或重新连接主机时，Paseo 检查 Codex 的归档列表，将已归档的对话从活动列表移除。检查在后台进行，不阻塞列表显示，包含已释放运行进程的对话，最多每 15 秒一次。检查超过 15 秒会结束检查进程；读取失败时保留现有状态。同步成功后自动更新列表，不再向 Codex 重复归档。

## 共用界面的调整

这些调整没有限定 Android，也会影响使用相应组件的其他平台：

- 紧凑布局中的共用菜单统一增加上下留白和行间距，包含对话、附件及其他使用同一菜单组件的入口。
- 待发送消息在限定高度内滚动，避免队列把输入区挤出屏幕。
- 紧凑布局顶部只留一行标题，去掉副标题、主机信息和原来的标签切换入口。
- 通用对话列表取消长按归档；Android 从侧栏或聊天页的对话菜单归档。

## Android：与原版同时安装

定制版和上游原版可以在同一台手机共存，应用数据和主机配对分别保存。切换到定制版需要重新配对，原版数据不会自动带过来。

本地日常 APK 默认只构建红米手机使用的 ARM64 架构，原生依赖也遵守这一限制，减少多架构编译开销；通用 APK 需显式选择。日常构建保留原生工程和构建缓存，只生成 App 所需的产物，并输出各阶段耗时。保留 JS 转换缓存，使用可访问的 Maven Central 镜像下载依赖；安装包仍可脱离 Metro 独立运行。真机安装入口复用同一优化构建，再覆盖安装并保留数据。

安装标识、构建和调试方式见 [Android 文档](android.md#app-variants)。
